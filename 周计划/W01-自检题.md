## 第 1 组：Agent Loop（核心中的核心，必须满分）

**Q1. 画出 Agent Loop 的五步链条。**

<details><summary>答案</summary>

```
目标 Goal → 思考 Reasoning → 行动 Action → 工具 Tool → 观察 Observation → 回到思考
```
关键点：**观察结果会塞回上下文**，模型看着新信息决定下一步。没有这一步回灌，就退化成"一次性问答"。
</details>

**Q2. "LLM 能联网搜索"这句话，准确版本是什么？**

<details><summary>答案</summary>

准确版：**LLM 只会输出一段文字（比如 `{"tool":"web_search","input":{...}}`），真正上网的是我写的 Python 代码。**

LLM 全程没有执行任何东西。想通这一点，你就不会再被"AI 自己能干活"这类说法唬住。
</details>

**Q3. 为什么 Agent 需要"循环"，而不是一次调用就够？**

<details><summary>答案</summary>

因为一次调用只能拿到一批信息，而真实任务需要**根据上一批结果决定下一批搜什么**。

昨天实测证据：模型第一次搜"字节跳动AI战略"结果质量差 → 它自己判断"需要换角度" → 改用 `web_fetch` 直接抓火山引擎官网。
**没有循环，就没有这个纠错机会。**
</details>

**Q4. Agent 的能力上限由什么决定？（三样）**

<details><summary>答案</summary>

1. **循环次数**（`max_steps` 设 2 会怎样？答案是报告质量直接塌）
2. **工具质量**（搜索返回垃圾，模型再聪明也白搭 —— 昨天就实测到了）
3. **提示词约束力**（我在提示词里写"资料不足就写'未能获取'，不许猜"，它才拒绝编造）
</details>

## 第 2 组：工程现实（决定你能不能交付给客户）

**Q5. 为什么"搜索后端"要设计成多个可切换？**

<details><summary>答案</summary>

因为**任何单一来源都会失败**。实测数据：
- DuckDuckGo 连续请求必限流（4 次挂 2 次）
- 百度直接反爬（返回"安全验证"页）
- Bing 稳定但中文质量差

所以做了"粘性偏好 + 失败自动切换"。**这是交付型和玩具型的分界线。**
</details>

**Q6. 昨天那次搜索失败，模型是什么反应？这说明什么？**

<details><summary>答案</summary>

它**没有编造**，而是：
1. 说"搜索结果质量不高"
2. 换关键词重试
3. 改用 `web_fetch` 直接抓目标站点
4. 最终报告里明确写"本轮搜索未能获取 XX 数据"

说明：**工具返回的错误信息也是"观察"的一部分**，模型读得懂。所以工具的错误提示要写清楚，别写"error"两个字就完事。
</details>

**Q7. 昨天跑一次研究花了多少钱？为什么要关心这个数？**

<details><summary>答案</summary>

一次约 **0.027 元**（26098 tokens，17 秒）。

为什么要关心：**你要拿这个数去跟客户报价。** 客户问"成本多少"，你答得出，可信度立刻不一样；
答不出，你就是个"我帮你搞个AI"的忽悠。W11 那个报价公式，原料就是这类数字。
</details>

## 第 3 组：商业思考（W01 真正的产出）

**Q8. 昨天那份报告，谁会付钱买？**

<details><summary>参考答案（你的答案可以不同，但必须具体）</summary>

具体到人和场景，不能写"企业"：
- **投资机构分析师**：看一个赛道 20 家公司，人工 2 天 → 现在 1 小时出初稿
- **咨询公司/券商**：写行业报告前的资料收集环节
- **中小企业战略部**：老板突然问"我们该不该上 AI"，需要一份能交差的材料
- **自媒体/公众号同行**：选题调研 → 这正是**你自己**的用途

❌ 不合格答案：「企业都需要」「市场很大」——这是空话，不是客户。
</details>

**Q9. 昨天你亲手跑的这套东西，最大的短板是什么？**

<details><summary>答案</summary>

**搜索质量不可控。** 零成本爬 HTML 的中文结果很差（实测首位常是完全无关的页面）。

商业含义：**现在这个 Demo 能演示，不能交付。** 真要接客户，必须配正规搜索 API（Tavily 等，有免费额度）。

> 这个判断能力比会写代码值钱得多 —— 客户最怕的就是"你连自己东西的短板都不知道"。
</details>

**Q10. 一句话讲给客户听：这个东西帮他省什么？**

<details><summary>参考答案</summary>

> "原来要一个人花两小时翻资料、整理成一份分析，现在 20 秒出一份初稿，**你只需要审核和改**。
> 而且它查不到的地方会明确告诉你查不到，不会瞎编。"

注意最后半句为什么重要：**企业客户最怕 AI 胡说，这句就是你的差异化。**
（同理，昨天 RAG 那条回答里的"建议人工复核"也是同一个卖点。）
</details>
