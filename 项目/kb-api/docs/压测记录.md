## 二、结果

### 2.1 并发梯度（混合问题 + 同题并发）

| 3 | 混合问题 | 6/6 | 1.05s | 1.68s | 1.68s | 2.63s |
| 3 | 超长输入(≈500字) | 3/3 | 1.42s | 1.42s | 1.42s | 1.43s |
| 10 | 同一问题 | 10/10 | 1.63s | 1.79s | 1.79s | 1.99s |
| 10 | 混合问题 | 10/10 | 1.18s | 1.53s | 1.53s | 1.54s |
| 10 | 超长输入 | 10/10 | 1.31s | 1.74s | 1.74s | 1.75s |
| 20 | 同一问题 | 20/20 | 1.52s | 2.25s | 2.25s | 2.39s |

**0 次失败、0 次 5xx、0 次超时。** 墙钟 ≈ 单次延迟，说明请求是真并行。

### 2.2 降级模式（no_llm=true，模拟没有 Key）

| 并发 | 请求 | 成功 | p50 | p95 | max |
|---|---|---|---|---|---|
| 3 | 6 | 6/6 | 0.02s | 0.03s | 0.03s |
| 10 | 20 | 20/20 | 0.04s | 0.06s | 0.06s |
| 20 | 24 | 24/24 | 0.09s | 0.11s | 0.11s |

**检索模式快 30~50 倍**：不调模型就没有网络等待。这也解释了为什么"演示不依赖额度"值钱。

### 2.3 边界校验（接口层拦截，不进模型）

| 输入 | 结果 | 耗时 |
|---|---|---|
| 空问题 | 422 `string_too_short` | 10ms |
| 501 字 | 422 `string_too_long` | 88ms |
| 500 字（边界）| 200，拒答（无命中）| 20ms |
| `top_k=0` / `11` | 422 | 6~7ms |
| `min_score=9` | 422 | 7ms |
| `no_llm=true` | 200，`mode="retrieval"` | 10ms |

### 2.4 模型不可用时的降级（实测）

把 `DEEPSEEK_API_KEY` 换成一个无效值，另起一个服务（:8111）打同一批问题：

| 端口 | 场景 | HTTP | 耗时 | mode | 返回 |
|---|---|---|---|---|---|
| 8100 | Key 正常 | 200 | 1834ms | llm | 模型总结 |
| 8111 | Key 无效 | **200** | 701ms | **retrieval** | `（模型暂时不可用，已降级为检索模式：LLMError）` + 原文片段 |
| 8111 | Key 无效 + 知识库外问题 | 200 | 31ms | retrieval | 拒答 |

**结论：Key 欠费/失效不会给客户看 500，会退回"只给原文片段"。** 这是 W05 加的一处兜底
（`server.py` → `do_rag()` 的 `try/except`）—— 演示中途额度用完也不翻车。

## 三、结论：能承诺什么，别承诺什么

| 场景 | 结论 |
|---|---|
| 现场演示（1 人操作）| ✅ 稳，1~2 秒 |
| 小团队试跑（≤20 人同时问）| ✅ 实测 p95 < 2.3s，无失败 |
| 30~40 人同时问 | ⚠️ 没测。线程池默认 40，超过会排队，延迟线性上涨 |
| 真实弱网（4G 差信号）| ⚠️ 没测。前端 90s 超时能兜住，但体验会差 |
| 模型 Key 失效 / 欠费 | ✅ 已测：HTTP 200 + `mode="retrieval"` + 原文片段（见 2.4）|
| 单进程挂了 | ❌ 全站不可用。上生产要 `--workers 4` + 进程守护 |

### 真正的瓶颈不是代码

延迟里 95% 是等模型。所以：
- 想更快 → 缓存高频问题（同一问题第二次直接返回）> 优化检索
- 想更省 → 先检索，命中低于阈值时**不调模型**（现在是 0.25 才调，已经省了）
- 想扛更多并发 → 多 worker / 异步 httpx 调模型（现在是同步 urllib 在线程池里）

## 四、这次压测没覆盖的（诚实标注）

1. **真实弱网**：用浏览器 DevTools 的 Network 限速（Slow 3G）手测一次即可，看前端加载态和超时提示
2. **断网/断电**：拔网线后页面应给出"连不上后端"，实测方法是停掉 server.py 再点一次
3. ~~Key 失效~~ —— **已测并通过**（见 2.4）。要复现：`$env:DEEPSEEK_API_KEY="sk-bad"; python server.py --port 8111`
4. **局域网多机**：`python server.py --host 0.0.0.0`，手机连同一 WiFi 打开 `http://<电脑IP>:8100`

> 第 4 条建议你亲手做：手机 + 电脑同时问，这才是"能进客户公司"的真实体感。
