### 本周最重要的三个发现（都是实测出来的）

**① 切片大小决定答案完不完整**

```
100 字切片 → 答案断在"1 天以内由"，后两步丢了
400 字切片 → 4 步完整
```
根因：「请假流程」一节约 150 字，100 字切片**物理上装不下**。

**② 词频检索有结构性缺陷**

```
问「标准版含有什么服务」
  保修与售后（含"服务"3次）  0.780  ← 排第一，但没答案
  产品资料（含"标准"）        0.309  ← 正确答案，被相对阈值砍掉
```
**它比的是"字面重复次数"，不是"意思对不对"。**

**③ 提示词治不了同义词**

```
问「保修期多久」→ 正确答案在"保修与售后"（写的是"服务期"）
  加了"同义词也算"的提示词后，LLM 仍给 3 分（认为答不了）
```
**结论：有些问题必须换结构，不能靠改提示词。**
