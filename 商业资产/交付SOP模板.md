# 交付 SOP —— 六步标准流程（W11 交付物）

> 目的：**让第 2 个客户比第 1 个快 3 倍**。
> 用法：每做完一个项目，回填实际工时。工时表攒够 3 个项目，你的报价就从"猜"变成"算"。

---

## 流程总览

```
1 需求分析 → 2 资料收集 → 3 Agent 设计 → 4 开发 → 5 部署 → 6 培训验收
   ↑ 最容易跳过                                              ↓
   └────────────── 复盘回填工时表 ←───────────────────────────┘
```

---

## 第 1 步：需求分析（目标工时：2h）

**要问的 10 个问题（照着念就行）：**
1. 现在这件事是谁在做？一天花多少时间？
2. 最烦的是哪一步？能不能举个例子？
3. 出错了会有什么后果？（决定要不要人工审核）
4. 资料都存在哪？（微信 / 网盘 / 纸质 / 系统）
5. 公司里谁最懂这些资料？
6. 谁来决定"这个回答对不对"？
7. 有多少人要使用？主要在哪用（群 / 网页 / App）？
8. 有没有不能外传的东西？（决定部署方式）
9. 你希望多久看到效果？
10. 如果只做最小的一块，你先要哪一块？

**输出物**：《需求确认单》，让客户在微信上确认一句"就按这个来"。
**红线**：没拿到这句确认，不许开工。

---

## 第 2 步：资料收集（目标工时：3h）

**清单：**
- [ ] 收集：把资料拿到手（超过 500 份就先抽样）
- [ ] 体检：标出重复的、过期的、互相矛盾的
- [ ] 清洗：转成可解析格式（PDF → 文字，图片 → OCR）
- [ ] 分级：机密 / 内部 / 公开（机密的不进库）
- [ ] 确认：让客户确认"资料全了 + 没有不该进的"

**输出物**：《资料体检报告》—— 这份东西**专门用来管理客户预期**。效果不好时它救你的命。

---

## 第 3 步：Agent 设计（目标工时：2h）

**决策表：**

| 客户特征 | 选择 |
|---|---|
| 只要问答，不要流程 | 知识库 RAG + 入口 |
| 要查业务系统（订单/库存） | RAG + FastAPI 工具接口 |
| 回答涉及钱/合同/法律 | 必须加**人工审核节点** |
| 内部使用、资料敏感 | 私有化部署 + 本地/私有模型 |
| 快速验证、预算少 | Dify 搭，不写代码 |
| 要深度定制、长期用 | 自研 + Dify 混合 |

**输出物**：流程图 + 技术选型一页纸（给自己看的）。

---

## 第 4 步：开发（目标工时：8-20h，视复杂度）

- [ ] 知识库搭建 + 切片调优
- [ ] Prompt 设计（含"不知道就说不知道"约束）
- [ ] 来源引用（可追溯到文件+段落）
- [ ] 多轮对话上下文
- [ ] 兜底策略（答不出 / 超时 / 报错 → 转人工）
- [ ] 后台：上传资料、看问答记录
- [ ] 造演示数据（⚠️ 别省这一步，Demo 好看程度一半靠它）

---

## 第 5 步：部署（目标工时：2-4h）

- [ ] 环境（客户服务器 / 我方云 / 本地）
- [ ] 域名 + HTTPS（如果要对外）
- [ ] 权限（谁能问什么 —— 不同部门资料要隔离）
- [ ] 备份（知识库 + 对话记录定期备份）
- [ ] 监控（报错能看到、成本能看到）
- [ ] 成本核算（每月 LLM 花费多少，写进交付说明）

---

## 第 6 步：培训 + 验收（目标工时：2h）

- [ ] 培训：20 分钟讲 + 录屏（录屏以后能重复用）
- [ ] 操作手册：一页图 + 5 个常见操作
- [ ] 验收标准：**在第 1 步就写进《需求确认单》**，验收时照着打勾
- [ ] 要三样东西：① 文字评价 ② 案例授权（可匿名）③ 1 个转介绍

## 报价公式（工时表攒够后用）

```
基础报价 = 实际总工时 × 你的时薪 × 风险系数

  你的时薪：起步阶段建议 ¥150-300/h（技术型独立开发者）
  风险系数：客户资料乱 +0.3 / 需求会变 +0.3 / 要私有化 +0.2 / 急单 +0.2

  例：24h × 200元 × 1.3 = ¥6,240   → 报 ¥6,800（整数好谈）

再加：
  年度维护费  = 一次性实施费 × 20% / 年
  第三方成本  = 服务器 + 模型 API，实报实销或客户自付
```

> ⚠️ 第一次别报太低。低价会让你累死且客户不珍惜。
> 免费试点是可以的，但**必须说清"正常价是多少"**，否则以后涨不上去。
