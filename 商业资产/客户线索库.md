# 客户线索库（W08 核心工具）

> 用法：**W01 就开始随手记，W08 集中打**。空着也行，但每周至少要添 1 条。
> 评分最后算总分，≥12 分的优先打。

## 字段说明

| 字段 | 填法 |
|---|---|
| 来源 | 熟人 / 本地商家 / 招聘平台 / 行业群 / 线上 |
| 痛点猜想 | 他可能有什么资料/客服问题（不确定就写"待验证"） |
| 触达状态 | 未触达 / 已发消息 / 已回复 / 已对话 / 有戏 / 已拒绝 |
| 痛点强度(1-5) | 他一天在这上面花多少时间？时间越久分越高 |
| 付费意愿(1-5) | 他聊到钱的态度：主动问价=5，只说"有机会合作"=2 |
| 我能交付(1-5) | 现有 Demo 改一改就能上=5，要重新做=2 |

## 触达话术（W08 Day2 用）

### 版本 A：熟人企业（先寒暄，后痛点）
> X 哥，最近忙啥呢？我这边在做一个 AI 的小东西，帮公司把内部资料变成"能直接问的问答助手"，员工查东西不用再翻群记录。
> 想找你请教一下：你们公司平时员工查资料/客户答问题，这块麻烦吗？我不推销，就是想把东西做对，想听听真实情况。

### 版本 B：陌生企业（不推销，只求 10 分钟）
> 您好，我是做企业 AI 自动化的独立开发者。最近在帮几家公司解决"资料太多、员工找不到"的问题。
> 想请教您一个行业问题（不涉及贵司内部信息）：您这个行业里，客服/销售查资料这块一般是怎么处理的？
> 如果方便，占用您 10 分钟电话，我把调研结果整理一份给您，算是回礼。

### 版本 C：行业群（先给价值，再加好友）
> 我们最近在做企业知识库问答的落地，整理了一份《中小企业知识库自查清单》（20 条），
> 有需要的同学我发你。也在找愿意聊 10 分钟真实痛点的老板，不做推销。

## 拒绝也是数据

被拒绝时必记：**他拒绝的理由是什么？**
- "我们有专门的人做这个" → 说明这活有价值，只是有人干了（可挖那个人的痛点）
- "太贵了" → 报价锚点错了，或价值没讲清
- "AI 不靠谱" → 需要案例和试点，这是行业普遍心理
- "以后再说" → 优先级不够 = 痛点不够痛，换人

**连续 5 个都拒绝且理由相同 → 你的方向选错了，回 W09 重选。**
