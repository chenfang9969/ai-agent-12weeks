# 每日记录 · 说明

这是你自己的本子。

- 想写什么就写什么
- 想写多少就写多少
- 不想写就不写

**没有格式要求，没有评分，没有"欠账"。**

---

推荐用法（只是建议，不是规矩）：

```powershell
python "D:\DeepSeekHarness\12周计划\today.py"
```

它会把今天的文件建好、用记事本打开。文件里只有日期和当天的任务，剩下空白。

---

如果你想有点结构，可以参考（但完全不必照做）：

- 今天搞懂了什么
- 卡在哪、后来怎么过的
- 有什么想法、吐槽、灵感
- 想对未来的自己说什么

---

## 关于考核（和本子无关）

计划本身的进度是**客观考核**的，但只看交付物，不看你的日记：

```powershell
python progress.py --check        # 本周交付物完成了吗
python progress.py                # 12 周资产进度
```

这两件事从一开始就该分开：**本子是你的，进度是事实的。**
