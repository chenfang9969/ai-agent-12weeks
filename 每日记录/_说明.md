# 每日记录 · 说明

这是你自己的本子。

- 想写什么就写什么
- 想写多少就写多少
- **不想写就不写**
- **不写不算欠账，没有评分**

---

推荐用法（只是建议）：

```powershell
python "D:\DeepSeekHarness\12周计划\today.py"
```

它会把今天的文件建好、用记事本打开。文件里只有日期、当天任务和下面那四个可选问题。

---

## 四个可选问题

**这四个是你自己在 12 周计划里定的**（原话是"每周固定习惯，非常重要 → 每天 30 分钟记录"）。
它们的用处是：**逼自己想那些平时会自然跳过的事。**

现在它们是**可选的**：

- 想按老规矩走一遍 → 四题都答
- 只想写点别的 → 随便写，跳过它们
- 今天什么都不想写 → **那就不写**

**框架提供给你，用不用你说了算。**

---

## 关于考核（和本子无关）

计划本身的进度是**客观考核**的，但只看交付物，不看你的日记：

```powershell
python progress.py --check        # 本周交付物完成了吗、证据在哪
python progress.py                # 12 周资产进度
```

**本子是你的，进度是事实的。这两件事从一开始就该分开。**
